Before you connect a repository, you need to know whether the features you want work on the Git host you use. Ankra connects to GitHub, GitLab and Bitbucket Cloud, and they do not all support the same things. This table is the single place that says which.

## What works where

| | GitHub | GitLab | Bitbucket Cloud |
|---|---|---|---|
| How you connect | The Ankra GitHub App | An access token, for GitLab.com or a self-managed instance | OAuth, per workspace |
| Webhooks | Delivered by the App - nothing to register | You add a webhook per project or group | Ankra registers them for you |
| Cluster [GitOps](/concepts/gitops) repository | Yes | No | Yes |
| [Applications](/concepts/applications) (Closed Beta) | Yes | No | No |
| [Ankra Pipelines](/guides/ankra-pipelines) triggers | Push, tag, pull request | Push, tag, merge request | Push, tag, pull request |
| [PR previews](/guides/pr-preview-environments) | Yes, for Applications | No | No |
| [AI code review](/platform/ai-code-review) | Yes | Yes | Yes |
| `@ankraai` mention replies | Yes | Yes | Yes |
| Agent-mode reply offers to open the fix as a pull request | Yes | No - it proposes a branch name and commit message | No - it proposes a branch name and commit message |
| [Merge when green](/guides/ankra-pipelines#what-a-pull-request-gets) | Yes | No | No |
| Related repositories for AI review | Yes | No | No |

Every AI capability is off on a new connection until an organisation admin switches it on. See [AI code review](/platform/ai-code-review).

## Events Ankra reads

| Provider | Events | What they drive |
|---|---|---|
| GitHub | `push`, `pull_request`, `issue_comment`, `pull_request_review_comment`, `workflow_run`, `repository` | GitOps sync, pipeline runs, AI review and mention replies, application builds |
| GitLab | Push, Tag push, Merge request, Comments | Pipeline runs, AI review and mention replies |
| Bitbucket Cloud | `repo:push`, `pullrequest:created`, `pullrequest:updated`, `pullrequest:comment_created`, `pullrequest:fulfilled`, `pullrequest:rejected` | GitOps sync, pipeline runs, AI review and mention replies |

On Bitbucket Cloud the pull request events need the credential to grant the `pullrequest` scope. See [Granting the pull request permission](/integrations/bitbucket-cloud#granting-the-pull-request-permission).

## Not supported

- **Bitbucket Data Center** and other self-hosted Bitbucket servers. A cluster spec naming `bitbucket_dc` is refused.
- **GitLab as a cluster's GitOps repository.** Keep cluster configuration on GitHub or Bitbucket Cloud. GitLab repositories can still run Ankra Pipelines and get AI review.
