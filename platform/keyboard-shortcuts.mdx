## From any page

| Action | Mac | Windows and Linux |
|--------|-----|-------------------|
| Open or close [Find](/platform/command-palette) | `⌘ K` | `Ctrl K` |
| Open or close Ask Ankra | `⌘ J` | `Ctrl J` |
| Close a dialog or Find | `Esc` | `Esc` |

In Find, `↑` and `↓` move through the results, `Enter` opens or runs the selected one, and `Esc` closes it.

## Cluster logs

The log explorer at **Clusters → &lt;your cluster&gt; → Kubernetes → Cluster logs** has its own shortcuts. Press `?` there to see them. They do not fire while you type in a field.

| Key | Action |
|-----|--------|
| `/` | Search |
| `J` or `↓` | Next line |
| `K` or `↑` | Previous line |
| `Esc` | Close the line |
| `F` | Follow new lines, or pause live logs |
| `P` | Lines or patterns |
| `W` | Wrap long lines |
| `?` | These shortcuts |

## Stack editor

| Action | Mac | Windows and Linux |
|--------|-----|-------------------|
| Save the resource you are editing to the draft | `⌘ S` | `Ctrl S` |
| Insert a secret reference in the source editor | `⌘ Shift S` | `Ctrl Shift S` |

## Ankra AI tickets

When you write a new ticket, `⌘ Enter` (`Ctrl Enter` on Windows and Linux) creates it.
