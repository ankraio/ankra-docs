**Find** is one search box that takes you to any page, application, cluster or setting, and runs common actions without leaving the keyboard.

## Open it

- Press `⌘ K` on macOS or `Ctrl K` on Windows and Linux, from any page. The same keys close it.
- Or click **Find** at the top of the sidebar, or in the top bar while the menu is hidden.

Use `↑` and `↓` to move through results, `Enter` to open or run the selected item, and `Escape` to close Find.

## What it finds

Results come in groups. Which groups show depends on where you are, what you type and what your role may see.

| Group | What is in it |
|-------|---------------|
| The open area's name (for example an application's or a cluster's) | Every view of what is open, the ones under **Technical details** included. In the organisation's settings this group is **Settings pages**. |
| **Applications** and **Clusters** | Applications and clusters whose name matches what you type. |
| **Pods · `<cluster>`** | Pods of the cluster you have open whose name matches. |
| **Tickets** | Ankra AI tickets, found by title or number (`T-1052`, `#1052` or `1052`). |
| **Variables** | Organisation variables whose name matches. |
| **Settings** | Every organisation setting by its plain name and the words people type for it, such as `2FA`, `SAML`, `API key` or `SOPS`. It opens the page and marks the section. Shown while you type, and before you type when you are in the organisation's settings. |
| **People** | Members of the organisation, by email. Opens what that person can do. |
| **Pages** | Every area of the sidebar and, while you type, the pages inside each area. |
| **Actions** | The actions below. |
| **Ask Ankra** | **Ask Ankra: `<what you typed>`** hands your words to Ankra AI as a question. |

## Actions

Each action shows only when your role allows it.

| Action | What it does |
|--------|--------------|
| **Create an application** | Opens the form that creates an application (`/next/applications/create`) |
| **Add a cluster** | Opens the page that creates or imports a cluster (`/next/clusters/new`) |
| **Get started with a free cluster and a website** | Opens the getting-started flow, where your organisation has it |
| **Review security fixes** | Opens **Security**, with the number of fixes waiting |
| **Review alerts** | Opens Ankra AI's alerts (`/next/ai/alerts`), with the number firing |
| **Create an Ankra AI ticket** | Opens a new ticket for Ankra AI |
| **Ask Ankra** | Moves the cursor to the Ask Ankra box |
| **Switch to light mode**, **Switch to dark mode**, **Match system appearance** | Changes the theme |
| **Show technical details** or **Hide technical details** | Shows or hides identifiers and exact values everywhere |
| **Support** | Opens Support |
| **Sign out** | Signs you out |

Find has no action that switches organisation. Use the organisation switcher in the sidebar, or **Your account → Organisations**: see [Your account](/platform/user-profile#organisations).

For the other shortcuts, see [Keyboard shortcuts](/platform/keyboard-shortcuts).
