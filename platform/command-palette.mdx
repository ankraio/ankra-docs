---
title: Command Palette
description: Jump to any page, cluster or Kubernetes resource and run common actions from one search box
---

Clicking through menus to reach a pod in a cluster three levels down is slow. The command palette is one search box that takes you to any page, cluster, add-on or Kubernetes resource, and runs common actions without leaving the keyboard.

## Open it

- Press `⌘ K` on macOS or `Ctrl K` on Windows and Linux, from any page.
- Or select **Search** in the sidebar.

Use `↑` and `↓` to move through results, `Enter` to open or run the selected item, and `Escape` to close the palette.

## Search

Type part of what you want. Matching is fuzzy and also checks each command's keywords, so `dep` finds **Deployments** and `registry` finds **Chart Repositories**. Results mix commands with live matches from your organisation: clusters, add-ons, manifests, Stacks and pods. Items you opened recently appear under **Recent** before you type anything.

When a cluster is open, the palette adds that cluster's pages (Stacks, Logs, Metrics, Operations, cluster settings) and every Kubernetes resource list, so you can jump straight to **Pods** or **Ingresses** in the current cluster.

## Examples

| Type | Command | What it does |
|------|---------|--------------|
| `kubeconfig` | **Download Kubeconfig** | Downloads a kubeconfig for the open cluster |
| `reconcile` | **Reconcile Cluster** | Opens the reconcile dialog for the open cluster |
| `ticket` | **Create Support Ticket** | Opens a new ticket for the Ankra team |
| `pdf` | **Export this page as a PDF report** | Saves the current page as a PDF |
| `password` | **Generate random password** | Opens a random password generator |
| `org` | **Switch Organisation** | Moves you to another organisation you belong to |

The palette also opens the AI chat (**AI Chat**) and a cheat sheet of every shortcut (**Keyboard Shortcuts**). For the full list of shortcuts, see [Keyboard shortcuts](/platform/keyboard-shortcuts).
