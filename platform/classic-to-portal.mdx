The classic Ankra portal is retired. If you learnt Ankra there, or follow an old link, an old bookmark or an older guide, this page says where each classic page is now. Old classic addresses in emails, pull request comments and bookmarks send you to the page in the right-hand column.

For the layout of the portal itself, read [Find your way around Ankra](/platform/find-your-way-around). [Portal addresses](/platform/portal-urls) lists every address.

## Where each classic page is now

`<id>` is the cluster's, application's or organisation's id in the address. Names in the left column are what the classic portal called things; what you click today is in bold on the right.

### Dashboard and clusters

| Classic | In the Ankra portal |
| --- | --- |
| Dashboard (`/organisation/dashboard`) | **Home** (`/next`), which opens on **Ask Ankra** |
| Clusters → Create Cluster for an import (`/organisation/clusters/create`, `/organisation/clusters/import`) | **Infrastructure → Clusters → Connect a cluster** (`/next/clusters/import`) |
| Importing a managed cluster (`/organisation/clusters/import-managed`) | **Connect a cluster → Find a managed cluster** (`/next/clusters/import?via=managed`) |
| Clusters → Create Cluster for a provider (`/organisation/clusters/create-<provider>`) | **Infrastructure → Clusters → Add a cluster** (`/next/clusters/new?provider=<provider>`) |
| Creating a playground (`/organisation/clusters/create-playground`) | **Get started** (`/next/onboarding`), or **Infrastructure → Clusters → Add a cluster** (`/next/clusters/new`), which offers the free trial or a paid size and **Create playground** |
| A cluster's overview and Troubleshooting | **&lt;your cluster&gt; → Overview** (`/next/clusters/<id>`) |
| A cluster's Metrics | **&lt;your cluster&gt; → Metrics** |
| A cluster's Security | **Security → Resources**, scoped to the cluster (`/next/security?scope=cluster&cluster=<id>&tab=resources`) |
| A cluster's Mesh | **Infrastructure → Cluster meshes** (`/next/meshes`) |
| A cluster's AI Insights | **&lt;your cluster&gt; → Overview**. There is no list of a cluster's AI insights |
| A cluster's Nodes | **&lt;your cluster&gt; → Technical details → Kubernetes → Nodes** |
| A cluster's node groups and control plane | `/next/clusters/<id>/node-groups`, reached from **Kubernetes → Nodes** |
| A cluster's Stacks, Create Stack and a Stack's history | **&lt;your cluster&gt; → Technical details → Stacks** (`/next/clusters/<id>/stacks`, `/stacks/new`, `/stacks/<name>/history`) |
| A Stack's backups tab | **&lt;your cluster&gt; → Backups**, filtered to the Stack |
| A cluster's Add-ons | **&lt;your cluster&gt; → Add-ons** |
| A cluster's Operations | **&lt;your cluster&gt; → Technical details → Operations** |
| A cluster's Backups | **&lt;your cluster&gt; → Backups** |
| A cluster's Kubernetes browser | **&lt;your cluster&gt; → Technical details → Kubernetes**, with the same paths. Pods sit at `kubernetes/pods`, and **Pod Disruption Budgets** under **Workloads** |
| A cluster's resources and manifests lists | **&lt;your cluster&gt; → Technical details → Stacks**. For a list of manifests, see [below](#tasks-with-no-portal-page) |

## Tasks with no portal page

These tasks have no page in the portal. Each has a CLI command.

<CliVersion since="0.77.0" />

| Task | Command |
| --- | --- |
| Resize a kept playground | `ankra cluster playground resize` |
| Set the number of pipeline workers on a cluster (the portal can only turn on one, with **Enable build execution** on an application's **Pipelines**) | `ankra cluster agent ci set --workers 2 --cluster <cluster-name>` |
| Start a debug pod | `ankra cluster debug create` |
| Move a cluster to another organisation | `ankra cluster move` |
| Stop a k3s cluster and keep its servers (pause) | `ankra cluster hetzner stop --mode pause`, and the same `stop` under `upcloud` and `digitalocean` |
| List a cluster's manifests | `ankra cluster manifests list` |
| Diagnose a bastion over SSH | `ankra cluster <provider> bastion diagnose` |
| Choose which agent works Ankra AI board tickets | `ankra ai board-identity provision` |
| Mirror board tickets into another tracker | `ankra tickets sync connections create` |
| Register an MCP server Ankra AI can call | `ankra org mcp-servers add` |
| Convert a GitHub Actions workflow to `.ankra/pipeline.yaml` | `ankra application pipeline convert` |
| Publish an application as an add-on | `ankra application publish-addon` |
| Launch a Stack profile demo | `ankra stack-profiles demo launch` |

Each command's flags are in the [CLI reference](/reference/cli/index).
