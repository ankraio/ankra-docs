title: AI automations
description: What an AI automation is, what happens to the automations your organisation already has, and what to use for scheduled and alert-driven AI work.
---

An AI automation is a workflow of several steps that Ankra AI runs from one trigger: a trigger node starts it, agent steps do the work, approval gates wait for a person, and an output node completes it with a message. Automations sit beside [AI agents](/platform/ai-agents), which have one goal on one trigger.

The portal has no page that creates, edits or lists automations, and the CLI has no command for them. The API serves them under `/org/ai-automations`.

## Automations your organisation already has

An automation created earlier keeps running on its trigger. Ankra checks for due automations every 30 seconds and, for each one:

1. Opens a run and enters the first node after the trigger.
2. Starts an agent session for each agent step, and moves on when the session finishes.
3. Pauses at an approval gate and files an `automation` ticket on **Ankra AI → Work** with the status awaiting approval. When a person approves the gate, the run moves on to the node behind it.
4. Completes at the output node, and resolves the ticket it filed.

While **Stop all AI** is on (**Ankra AI → Autonomy and approvals → Stop Ankra AI**), a due automation records a skipped run instead of running. See [Stopping Ankra AI](/platform/ai-overview#stopping-ankra-ai).

## What to use instead

| You want | Use | Read more |
| --- | --- | --- |
| Ankra AI to investigate, and fix where you allow it, when an alert fires | A watch on **Ankra AI → Watching** | [Watch for a problem](/guides/ai-watching) |
| A goal to run on a schedule | An agent with a `cron` trigger, from `ankra ai tasks create` | [AI agents](/platform/ai-agents#hire-create-and-change-agents) |
| Findings from the health check filed as tickets | **Automatic insight tickets** on the ticket desk | [Set up the ticket desk](/guides/ticket-desk) |
| A person to approve a change before it happens | Autonomy `propose` on the agent, or **Ask first** for alert fixes | [AI Autonomy](/platform/ai-autonomy) |
