## ankra delete

Delete a resource (e.g., a cluster) from the Ankra platform.

## ankra delete cluster

Delete a cluster by name. For an imported cluster this is Disconnect
cluster: it removes the cluster from Ankra and changes nothing inside it, and
it works while the agent is offline. 'ankra cluster deprovision' is not the way
to remove an imported cluster: it needs the agent online and keeps the cluster
in Ankra.

```bash
ankra delete cluster NAME [flags]
```

**Flags**

| Flag | Default | Description |
|------|---------|-------------|
| `--dry-run` | `false` | Show what would be deleted without calling the API |
| `-f`, `--force` | `false` | Skip confirmation prompt |
