## ankra tokens

Commands to list, create, revoke, and delete API tokens.

## ankra tokens create

Create a new API token

```bash
ankra tokens create <name> [flags]
```

**Flags**

| Flag | Default | Description |
|------|---------|-------------|
| `--expires` |   | Token expiration date (ISO 8601 format) |
| `-o`, `--output` |   | Output format: json or yaml (default: human-readable) |
| `--scopes` | `[]` | MCP access scopes: mcp:read or mcp:read,mcp:write; omitted creates a REST-only token |

## ankra tokens delete

Delete an API token. The token must be revoked first.

```bash
ankra tokens delete <token_id>
```

## ankra tokens list

List your API tokens with when each one expires.

A live token that expires within 7 days reads "Expiring" in the Status
column and an expired one "Expired"; the Expires column shows the date and
how many days are left. Replace an expiring token before it stops working:
create a new one, put it where the old one is used, then revoke the old one.

```bash
ankra tokens list [flags]
```

**Flags**

| Flag | Default | Description |
|------|---------|-------------|
| `--order` | `asc` | Sort direction with `--sort`: asc or desc |
| `-o`, `--output` |   | Output format: json or yaml (default: human-readable) |
| `--sort` |   | Sort by column: id, name, status, created, expires, last-used (default: server order) |

## ankra tokens revoke

Revoke an API token (can be deleted after)

```bash
ankra tokens revoke <token_id>
```
