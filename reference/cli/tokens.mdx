## ankra tokens

Commands to list, create, rotate, revoke, and delete API tokens.

## ankra tokens create

Create a new API token

```bash
ankra tokens create <name> [flags]
```

**Flags**

| Flag | Default | Description |
|------|---------|-------------|
| `--expires` |   | Token expiration date (ISO 8601 format) |
| `-o`, `--output` |   | Output format: json or yaml (default: human-readable) |
| `--scopes` | `[]` | MCP access scopes: mcp:read or mcp:read,mcp:write; omitted creates a REST-only token |

## ankra tokens delete

Delete an API token. The token must be revoked first.

```bash
ankra tokens delete <token_id>
```

## ankra tokens list

List your API tokens with when each one expires.

A live token that expires within 7 days reads "Expiring" in the Status
column and an expired one "Expired"; the Expires column shows the date and
how many days are left. Renew an expiring token before it stops working with
"ankra tokens rotate &lt;id&gt;".

```bash
ankra tokens list [flags]
```

**Flags**

| Flag | Default | Description |
|------|---------|-------------|
| `--order` | `asc` | Sort direction with `--sort`: asc or desc |
| `-o`, `--output` |   | Output format: json or yaml (default: human-readable) |
| `--sort` |   | Sort by column: id, name, status, created, expires, last-used (default: server order) |

## ankra tokens revoke

Revoke an API token (can be deleted after)

```bash
ankra tokens revoke <token_id>
```

## ankra tokens rotate

Issue a new token to replace one that is about to expire, with the same
name and scopes. The old token keeps working for an overlap window so you can
update every place it is used, then it stops by itself.

The new token value is shown once. When stdout is not a terminal the command
prints only the value on stdout, so this works in scripts:

```bash
TOKEN=$(ankra tokens rotate <token_id>)
```

All other text goes to stderr. With -o json the whole response is printed.

Use `--service` to rotate an organisation service token instead of a personal
one. `--overlap-hours` sets how long the old token keeps working, from 0 (stops
at once) to 168; the platform default is 24 hours.

```bash
ankra tokens rotate <token_id> [flags]
```

**Examples**

```bash
ankra tokens rotate 5b1c0d52-0000-0000-0000-000000000000
  ankra tokens rotate <token_id> --overlap-hours 72
  ankra tokens rotate <token_id> --service -o json
```

**Flags**

| Flag | Default | Description |
|------|---------|-------------|
| `-o`, `--output` |   | Output format: json or yaml (default: human-readable) |
| `--overlap-hours` | `24` | Hours the old token keeps working (0-168) |
| `--service` | `false` | Rotate an organisation service token instead of a personal token |
