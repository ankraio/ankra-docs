## ankra deployments

Inspect deployments: each 'kind: deploy' pipeline stage that ran releases
one published artefact digest to every active host target of its environment,
and each deployment records how every host fared.

## ankra deployments get

Show a deployment and how each host target fared

```bash
ankra deployments get <id> [flags]
```

**Flags**

| Flag | Default | Description |
|------|---------|-------------|
| `-o`, `--output` |   | Output format: json or yaml (default: human-readable) |

## ankra deployments list

List deployments, newest first

```bash
ankra deployments list [flags]
```

**Examples**

```bash
ankra deployments list --environment production
  ankra deployments list --repository <pipeline-repository-id> -o json
```

**Flags**

| Flag | Default | Description |
|------|---------|-------------|
| `--cursor` |   | Continue from the cursor a previous page printed |
| `--environment` |   | Only list deployments to this environment |
| `--limit` | `0` | Deployments per page (default: the platform's page size) |
| `-o`, `--output` |   | Output format: json or yaml (default: human-readable) |
| `--repository` |   | Only list deployments from this pipeline repository id |
